内容系统导入规则

内容系统（图书 / 单词 / 句子 / 标准音 / 汉语意思）→ 小程序各页面内容与题目的生成口径

目标
对接内容系统全部图书。内容系统提供「原子素材」——单词、句子，及其标准音、汉语意思、音标、词性、句子↔单词关联。所有题目（选择题、听音填空挖空、组卷、干扰项、测评抽样）均由后端按本节规则生成并以现成题目对象下发；前端只负责渲染、采集作答与上报耗时，不在前端拼题。本节即后端出题口径：素材结构 → 导入/分关 → 各环节形态 → 出题规则 → 抽样组卷 → 缺数据兜底。
前后端分工（已定：题目全部后端下发）
· 后端：导入内容系统素材 → 分关 → 生成每种题目（含选项/干扰项、听音填空的挖空位与字母块、测评抽样组卷）→ 以现成题目对象下发。
· 前端：按下发的题目对象渲染交互，采集作答对错 / 录音评分 / 各题耗时并上报；不计算挖空、不抽干扰项、不组卷。
· 随机可复现：打乱与挖空用后端固定 seed（题ID/levelId/examId），保证报告、复查、重练一致。
⚠ 接口影响（现状缺口，需补）
既然题目全部后端下发，现状有缺口：当前关卡小测、单词新学选择题是前端拿 unit-words 原始词表自己拼题的，与「全部后端下发」不符，需调整：

一、内容系统原子结构
内容系统按「图书 → 单元 → 单词 / 句子」三层组织；单词与句子是最小素材，各带标准音与汉语意思。
层级关键字段说明

关卡切分（分关）规则
关卡不直接等于内容系统单元，而是把全书单词按原顺序、每 10 个切一关（LEVEL_SIZE=10，可配）。余数按下列处理：
情况处理示例（总词数 → 关卡词数）
整除每 10 词一关30 → 10 / 10 / 10
余数 r < 5并入最后一关（末关 10+r 词）23 → 10 / 13；34 → 10 / 10 / 14
余数 r ≥ 5独立成最后一关（末关 r 词）25 → 10 / 10 / 5；27 → 10 / 10 / 7
总词数 < 10整本仅一关（不足 10 也成关）8 → 8
配套约定：
点约定
词序按内容系统原始顺序切，不打乱、不跨书混排，保证教材顺序
句子归属句子按 wordRefs 命中的单词跟随所在关卡；命中多关取「命中词最多」的关；无命中则按句子在书中的原始位置归入对应关卡（与单词同一套顺序）
编号学习关连续编号「关卡1…N」；复习关不占学习关序号（每 3 个学习关后插 1 复习关，见核心三环节章）
复习关不参与 10 词切分，词表/题目由 review-words 按历史错词下发
内容系统单元已定：固定每 10 词切，忽略内容系统单元边界；单元仅作素材分组 / 句子归属参考，不映射关卡

四、选择题怎么出（新学验证 + 测评共用）
一道四选一选择题的装配链路：
步骤规则
① 选方向看词选义（题干 word，选项 meaning）/ 看义选词 / 听音选词（题干放 audioUrl）。新学验证默认「看词选义 + 播音」；测评按题型配比混出
② 正确项目标词对应的另一面（meaning 或 word）
③ 干扰项 ×3从同范围词池抽：新学验证 = 同单元；测评 = 全书。同词性优先 → 不足按 相邻单元 → 全书 补；去重；不得与正确项文本相同
④ 打乱4 个选项随机排序，记录正确索引；用 seed = 题ID 伪随机，同一题每次进入顺序一致（便于报告/复查）
⑤ 判分对 = 100 / 错 = 0；新学环节再与「认识自评」组成 2×2（见算分规范 5.6①）
五、听音填空 · 挖空怎么抽（核心）
小测第 1 题：听标准音 → 用字母块拼出单词。不是整词重拼，而是给出部分字母、挖掉若干空，规则如下（常量可调）：
环节规则
挖几个空 n按词长 L 取：L≤3 → 1；L=4–6 → 2；L=7–9 → 3；L≥10 → 4。等价 n = clamp(round(L × 0.35), 1, 4)（BLANK_RATIO=0.35）
挖哪些位置① 首字母保留（定位锚点，KEEP_FIRST=true）；② 优先挖元音 a/e/i/o/u（听→拼的难点），元音不足再挖辅音；③ 不挖相邻两位（避免连续空过难）；④ 重复字母不全挖（保留可推断）
可复现挖法用 seed = word + levelId 伪随机 → 同一词每次挖同样的空，复习 / 报告 / 重练一致
字母块候选块 = 被挖的正确字母 + 2~4 个干扰字母（从该词其他字母 / 易混字母 b-d、p-q 抽），整体打乱
判分全部空填对 = 100；多空按 填对空数 / 总空数 × 100（对齐算分规范 5.6③）
示例：computer（L=8 → n=3，保留首字母 c）→ 挖元音 o / u / e → 显示 c_mp_t_r，给字母块 [o][u][e][a][i] 让其拖入。
六、背诵评测 / 跟读取材
· 小测背诵评测：给该词 meaning（脱稿，不给拼写/音频），用户朗读 → 语音对该词 audioUrl 评分（无选项、无干扰项）。
· 环节2 跟读：单词读音 + 该词关联句子（wordRefs 命中的 Sentence）跟读；单词分与句子平均分各半（算分规范 5.6②）。无句子则只跟读单词。
七、关卡小测怎么组卷（全覆盖，不抽样）
小测是本关检验，覆盖单元全部单词，不抽样：
项规则
题量= 单元词数 × 2（每词：听音填空 1 + 背诵评测 1）
顺序按词逐个出「填空 → 背诵」，或先全部填空再全部背诵（页面已分两步）；词序可随机但用 seed=levelId 复现
跳过词无 audioUrl → 该词听音填空降级或跳过（见兜底）；背诵评测仍可（有 meaning 即可）
汇总每词 2 题 → 该词小测 cell（算分规范 5.6③）→ listening-quiz-result 上报
八、入门测 / 结业测怎么组卷（抽样）
测评是词书维度的卷子，从全书素材抽样组卷（区别于小测的全覆盖）：
项入门测 entry结业测 exit
目的摸基础（学前）查通关成效（学后），与入门同维度对比
题量较少（建议 ~20 题，EXAM_TOTAL 可配）较多 / 覆盖更广，题型与模块配比和入门测一致（保证 entryCompare 可比）
模块单词模块 + 句子模块（与 exam-report 的两模块对齐）；配比建议 词 70% / 句 30%，或按全书 word:sentence 比例
题型配比单词模块：英译中 / 中译英 / 听音选词 / 听音填空 按比例混合；句子模块：句子挖空 / 句子翻译选择 / 连词成句 order（现有题型）
抽样按单元分层均匀抽，覆盖各单元（覆盖率可低，~60%）分层抽，覆盖面更广（接近全书）
去重 / 干扰项一套卷同一词只出一次；干扰项范围 = 全书（跨单元），同词性优先
顺序题序、选项序随机但可复现（seed=examId）；可按题型先易后难排
次数每书仅一次（entryCompleted）可多次（建议后端限次）
判分每题 0/100 → 模块正确率 → 总正确率；grade / statusText 分档见「测评/报告」章 + exam-report-copy.js
九、选项 / 干扰项通用细则
· 选择题固定 4 个选项（1 正确 + 3 干扰）；选项随机打乱并记录正确项索引。
· 干扰项优先同单元、同词性；同单元不足 4 个可用项时，按「同词书相邻单元 → 全书」逐级补足。
· 干扰项需去重，且其文本（meaning / word）不得与正确项相同（防同义词撞答案）。
· 听音类题型必须有 audioUrl；句子挖空类必须句子带 trans 且 wordRefs 命中本单元词。
· 同一关卡内同一单词不重复出题（除非单元词数不足以铺满题量，此时允许换题型复用）。

★ 核心学习流程 · 每关三环节

单词新学 → 跟读背诵 → 关卡小测；错词由前端上报、后端汇总，决定复习关内容

流程
首页点关卡任务 → unit-words 拉内容 → 环节 1/2 在 practice、环节 3 在 listen?mode=quiz → 每环节结束进 finish/today → save-learning-record 更新该关 tasks[] → 刷新 book-units。每 3 关插入复习关，复习词表由后端根据历史错词返回（review-words），不是前端 Mock。
数据分工
· 前端提交：单词认选结果、跟读/背诵分数、小测对错、各环节/各题耗时（durationSeconds）
· 后端存储&决策：掌握态、任务进度、错词池、按日汇总学习时长（供报告/学习记录/user/info）
· 前端只读：book-units.tasks[]；复习词表 review-words；报告里的 minutes / 三环节用时均由后端返回
学习时长 · 全程记录
练习、小测、测评、随身听播放全过程都要记时，不能只记结果不记耗时。前端在环节/题目/播放结束时上报 durationSeconds（建议同时带 startedAt/finishedAt），后端汇总为：
· 单关报告 unit-report.minutes + taskDurations{word,recitation,listening}
· 每日学习记录 study-records.records[].minutes、audioMinutes
· 我的页 / user/info studyMinutes
· 测评报告 exam-result.durationSeconds + reportGeneratedAt
· 关卡报告 unit-report 各环节 sectionScores.*.submittedAt + 报告 reportGeneratedAt

关卡报告 · 计算规则（3环节 → 单词掌握 → 报告）
单关报告由后端按 resBookId + unitId（levelId）+ userId 查询（userId 走登录态，不入 query）。下为完整计算口径（正文嵌入，无需另开文件），详版见 docs/level-score-review-spec.md。
三件事分开，不混用：① 可练性=永远允许重练（不锁关）；② 计分=展示分取历史最高 maxScore，只升不降（另存 latestScore 供分析）；③ 复习触发=由首次练习数据决定（不随重练改变）。一句话：分数取最高（给人看），复习锚首次（给学习用）。
① 词 × 环节矩阵（所有报告数字的唯一来源）
一个词经 单词新学 / 跟读背诵 / 关卡小测 三环节，同词可能某环节对某环节错。报告的 总正确率、已掌握数、待复习数全部从同一张矩阵推导，保证自洽：
词单词新学跟读背诵关卡小测→ 词掌握度（行）
apple1009610098 ✅ 已掌握
pencil100704061 ⚠️ 待复习
环节分（列）958992总正确率 = 各词掌握度平均
列聚合=环节表现（报告「环节卡」三个分）；行聚合=单词掌握度（决定该词去复习/已掌握）；总正确率=所有词掌握度的平均（与 已掌握数/待复习数 同源）。
② 词掌握度（行）= 加权，小测最重
三环节考的不是一回事，不简单平均：
环节考的是权重
单词新学认不认识（过程）20%
跟读背诵发音 / 产出30%
关卡小测是否真记住（检验）50%
例：pencil = 100×0.2 + 70×0.3 + 40×0.5 = 61 → 待复习。压在小测上可自动解掉跨环节对错冲突（先会后忘=没掌握）。
缺失环节归一化：某词只参与部分环节时，按其实际参与的环节重新归一化权重，缺失环节不当 0 分（如未进小测 → 仅新学20/跟读30 归一为 40%/60%）。
③ 各环节单格（cell）怎么算 → 都归一到 0–100
· 单词新学 = 自评 × 选择题（2×2）
认识自评选择题cell 分含义
认识对100真会
认识错30自以为会（最该抓）
不认识对70蒙对 / 会一点
不认识错50老实承认（新词正常）
· 跟读背诵 = 单词读音 + 句子，各占一半　cell = 单词读音分 × 0.5 + 句子平均分 × 0.5
组成怎么得分占比
单词读音该词跟读的 Chivox 发音分 0–10050%
句子该词关联例句（wordRefs 命中）各自发音分，先在句子内部平均，再与单词各半 → 句子条数多不冲淡单词读音50%
边界无句子 → cell = 单词读音分；某句评分失败 → 跳过该句，句子内部重新归一
· 关卡小测 = 每词 2 小题，等权平均　cell = (听音填空分 + 背诵评测分) / 2
小题怎么得分占比
