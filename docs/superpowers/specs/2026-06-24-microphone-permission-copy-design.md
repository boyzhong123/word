# 麦克风授权引导文案设计

## 目标

让用户明确理解当前引导按钮只会唤起微信系统授权弹窗，真正的麦克风授权需要在系统弹窗中点击「允许」。

## 文案

- 标题：跟读需要麦克风
- 说明：需要录下你的发音进行评分。点击「继续」后，请在系统弹窗中选择「允许」。
- 按钮：继续

## 交互

保留现有授权链路。用户点击「继续」后进入录音流程，由现有媒体组件唤起系统麦克风授权弹窗；用户在系统弹窗中选择「允许」后开始录音，拒绝时继续沿用现有的设置引导。

## 验收标准

- 引导不再暗示点击当前按钮即可完成授权。
- 文案明确指出需要在系统弹窗中选择「允许」。
- 点击按钮后的授权与拒绝处理逻辑不变。
