# 今日学习路线紧凑进度设计

## 目标

压缩“今日学习路线”头部的纵向空间，并让用户优先看到有行动价值的学习进度。

## 已确认方案

- 保留左侧路线图标、标题和右侧“学习计划”按钮。
- 用紧凑进度条替换标题下方的“更新时间”。
- 进度条右侧显示已完成步骤数与总步骤数，例如 `1/3`。
- 删除头部下方原有的口哨—进度条—旗帜整行。
- 进度数据继续使用现有的 `doneSteps`、`totalSteps` 和 `stepPercent`，不改变进度计算逻辑。

## 布局与状态

- 新进度位于 `.route-title` 下方，与标题左对齐。
- 进度轨道保持绿色完成态和浅灰未完成态，尺寸缩小以适配标题区。
- 当进度为 0 时允许填充宽度为 0，不强制显示最小绿色圆点。
- 总步骤数正常情况下大于 0；若数据尚未准备好，文本显示 `0/0`，不引入额外占位状态。
- 下方首个关卡卡片自然上移，沿用现有卡片间距。

## 实现范围

- 修改 `pages/today/today.wxml` 的路线头部结构。
- 修改 `pages/today/today.wxss` 的进度样式，并删除旧整行进度样式。
- 不修改学习计划按钮、路线图标、关卡卡片或业务数据计算。

## 验证

- 验证 0%、部分完成和 100% 三种进度的宽度与数字。
- 验证窄屏下标题、进度和“学习计划”按钮不重叠。
- 运行今日页相关自动化测试，确认既有交互和数据状态不受影响。
