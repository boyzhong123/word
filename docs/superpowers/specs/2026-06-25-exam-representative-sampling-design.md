# 入门测 / 结业测代表性抽样设计

## 目标

入门测和结业测应在有限题量内尽量扩大对整本书知识点的覆盖面，避免同一个单词先作为单词题考查，又在句子题中作为核心答案重复考查，导致题量被重复考点占用。

## 核心概念

每道题必须标记一个或多个 `testedWordRefs`，表示该题真正计分、真正考查的目标单词。

- 单词题：目标单词本身是 `testedWordRefs`。
- 句子挖空：被挖掉并要求作答的单词是 `testedWordRefs`。
- 句子翻译、连词成句：句子关联词中由后端选定的代表词是 `testedWordRefs`；若题目考查整句，可标记该句全部核心关联词。
- 句子中仅作为上下文出现、但不要求用户识别或填写的单词，不算本题主考点。

## 组卷原则

### 1. 覆盖优先

后端先按单元分层抽取候选素材，再按以下优先级选题：

1. 覆盖尚未考查的单元。
2. 覆盖尚未考查的目标单词。
3. 保持单词题与句子题、各题型的目标配比。
4. 在覆盖相同的候选中，优先选择字段完整、题目质量更高的素材。

### 2. 主考点去重

同一套试卷中，同一个目标单词原则上只能进入一次 `testedWordRefs`。

例如：

- 已用单词题考查 `brave`，后续句子题不得再把 `brave` 作为挖空答案或代表词。
- 句子 `A brave person has courage.` 同时关联 `brave` 和 `courage`。若 `brave` 已考过、`courage` 未考过，该句仍可用于考查 `courage`。
- 已考单词可以作为句子的普通上下文出现，只要它不是该题答案或计分考点。

因此，去重对象是“主考点”，不是简单按句子是否包含已考单词整句排除。

### 3. 代表性

抽样时应尽量做到：

- 各单元均匀覆盖，不集中在前几单元。
- 不同词性、难度和题型合理分布。
- 句子题优先选择 `wordRefs` 清晰、中文翻译完整、长度适中的句子。
- 听音题只选择有有效 `audioUrl` 的素材。
- 同一套卷不使用同一句子生成多道题。

## 入门测与结业测

- 入门测题量较少，优先扩大单元和目标单词覆盖面。
- 结业测覆盖更广，但题型、模块比例和难度结构应与入门测一致，以保证成绩可比。
- 为了前后测可比，建议按相同的“抽样蓝图”选择单元、词性、难度和题型，但使用同层级的不同目标单词或不同句子；不要求两套卷考查完全相同的具体词。

## 内容不足时的降级顺序

目标题量无法在主考点完全去重的情况下满足时，按以下顺序降级：

1. 允许调整单词题与句子题比例，用未考查的有效素材补足。
2. 允许减少题量，优先保证题目有效和覆盖真实。
3. 仍需达到配置的最低题量时，才允许复用已考目标单词，但必须更换题型，并将重复次数控制为一次。
4. 无句子时只出单词题；无音频时跳过听音题。
5. 有效题目低于最低开考数量时，不生成空题或劣质题，返回测评不可用状态及原因。

推荐配置：

- `EXAM_MIN_TOTAL = 5`
- `MAX_TESTED_WORD_REPEAT = 1`

## 接口建议

`GET /mini-app/exam-paper` 返回的每道题增加：

```json
{
  "id": "s12",
  "section": "sentence",
  "sourceUnitId": "unit-3",
  "sourceSentenceId": "sentence-28",
  "testedWordRefs": ["courage"],
  "isRepeatedTarget": false
}
```

试卷级增加覆盖摘要，便于后端自检和联调：

```json
{
  "coverage": {
    "unitCount": 8,
    "coveredUnitCount": 8,
    "uniqueTestedWordCount": 19,
    "repeatedTargetCount": 1
  }
}
```

这些字段不参与前端答题交互，但可用于报告解释、质量审计和自动化测试。

## 验收标准

- 素材充足时，`repeatedTargetCount` 必须为 `0`。
- 单词题考过的目标词，不得再次成为句子题的答案或代表词。
- 已考目标词可以作为句子普通上下文出现。
- 每个有有效素材的单元应至少被覆盖一次，除非题量小于单元数。
- 素材不足时必须按既定顺序降级，不生成空选项、无答案或缺关键字段的题。
- 相同 `examId` 生成的题目、选项和覆盖摘要必须可复现。
