# 关卡成绩与复习规则 — 接口/字段约定

> 适用范围:首页所有关卡的「练习 → 成绩 → 复习」闭环。
> 目的:统一前后端口径,避免成绩、掌握度、复习三套数字互相打架。

---

## 1. 核心原则:三件事分开,口径不混用

| 维度 | 含义 | 决定者 | 不要和谁绑死 |
|---|---|---|---|
| **可练性** | 关卡能不能反复进 | 永远允许重练 | 不和"计不计分"绑 |
| **计分规则** | 重练后分数怎么记 | 取历史最高,只升不降 | 不和"能不能练"绑 |
| **复习触发** | 哪些词进复习、何时毕业 | 由**首次**练习数据决定 | 不和"练了几次"绑 |

一句话:**分数取最高(给人看,要鼓励)、复习锚定首次(给学习用,要真实)。**

---

## 2. 可练性 & 计分规则

- 关卡练过后**永远允许再次练习**(学习类产品底线,不锁关)。
- 首页/星级展示分用 **历史最高分(maxScore),只升不降**。
- 后台同时保留 **最近一次成绩(latestScore)** 与每次的答题记录,用于分析与复习。
- 乱点重练不会冲掉好成绩;认真重练可以把分数往上刷。

---

## 3. 晋级 gate(星级)

复用现有 `starsForScoreRate`:

| 关卡总分 | 星级 | 是否解锁下一关 |
|---|---|---|
| < 55 | ⭐ 1 星 | ❌ 留在本关继续刷 |
| 55 – 79 | ⭐⭐ 2 星 | ✅ 解锁 |
| ≥ 80 | ⭐⭐⭐ 3 星 | ✅ 解锁 |

**规则:关卡总分 ≥ 55(满 2 星)才解锁下一关,否则留在本关刷。**

---

## 4. "首次"的定义

- **首次 = 第一次提交成绩那一次**(产生正式成绩的那次)。
- 中途退出 **不算首次**:接口只记录答题 log,不产生成绩、不锁复习种子。
- 即:`首次 = 第一条 status=completed 且 submitted=true 的练习记录`。
- 存量老用户:取现有最早一条完成记录回填;无记录则对该用户用"最近一次"兜底,避免复习为空。

---

## 5. 报告计算:词 × 环节矩阵(核心)

一个词会经过多个环节(单词新学 / 跟读背诵 / 关卡小测),同一个词可能某环节对、某环节错。
所有报告数字都从**同一张「词 × 环节」矩阵**推导,保证自洽。

### 5.1 矩阵示例

| 词 | 单词新学 | 跟读背诵 | 关卡小测 | → 词掌握度(行) |
|---|---|---|---|---|
| apple | 100 | 96 | 100 | 98 ✅ 已掌握 |
| pencil | 100 | 70 | 40 | **64 ⚠️ 待复习** |
| … | … | … | … | … |
| **环节得分(列)** | **95** | **89** | **92** | **总正确率 92%** |

- **列聚合** = 环节表现(95 / 89 / 92)。
- **行聚合** = 单词掌握度(pencil 64%)。
- **总正确率** = 所有词掌握度的平均(自下而上,使 `正确率 / 已掌握数 / 待复习数` 同源)。

### 5.2 行聚合(词掌握度)= 加权,小测权重最高

三个环节考的不是同一回事,**不要简单平均**:

| 环节 | 考的是 | 建议权重 |
|---|---|---|
| 单词新学 | 认不认识(过程) | 20% |
| 跟读背诵 | 发音 / 产出 | 30% |
| 关卡小测 | 是否真的记住(检验) | **50%** |

> 示例:pencil = `100×0.2 + 70×0.3 + 40×0.5 = 61` → 待复习。

**为什么压在小测上(自动解掉跨环节对错冲突):**
- 新学蒙错、小测对了 → 偏已掌握(最终学会了才算数)。
- 新学对了、小测错了 → 偏待复习(前面会、最后忘 = 没掌握)。

### 5.3 缺失环节的归一化(必须处理)

某词若只出现在部分环节(如未进小测):**权重按该词实际参与的环节重新归一化**,缺失环节不当 0 分。
> 例:pencil 未进小测 → 仅 新学20 + 跟读30 归一为 40% / 60%,避免"跟读很好却被冤判待复习"。

### 5.4 掌握度阈值(独立可调常量)

- **词掌握度 < 70 → 待复习;≥ 70 → 已掌握**(`MASTERY_THRESHOLD = 70`,可调)。
- 此阈值**独立于** 55/80 的星级档:
  - 星级档(55/80)= "关卡能不能过",给晋级用。
  - 掌握度阈值(70)= "词要不要复习",给学习用。

### 5.5 题目 → 词级 cell:统一三层算分

所有题目走同一条链路,各环节不要各搞一套:

```
题目分(0-100) → 等权平均 → 词×环节 cell(0-100) → 加权 → 词掌握度
   第1层            第2层          矩阵格子            第3层(见 5.2)
```

**第 1 层统一口径:每道题归一到 0–100**(对错题 → 0 或 100;发音/连续分 → 原分)。
之后第 2 层只是"等权平均",不管几道题、什么题型都通用。

> 现状:`computeWordNewScoreRate` / `computeQuizScoreRate` 目前是**环节级**(直接对全环节求平均),
> 缺**词级 cell**。需新增词级聚合,使 5.1 矩阵的每个格子可算。

### 5.6 各环节 cell 计算规则

#### ① 单词新学 = 自评 × 选择题验证(2×2)

| 认识自评 | 选择题 | cell 分 | 含义 |
|---|---|---|---|
| 认识 | 对 | 100 | 真会 |
| 认识 | 错 | 30 | 自以为会(最该抓) |
| 不认识 | 对 | 70 | 蒙对 / 其实会一点 |
| 不认识 | 错 | 50 | 老实承认不会(新词正常) |

> "不认识"是新词首次接触的正常状态,**不重罚**;本环节真正价值是揪出"高估自己"(认识+错=30)。
> 替代现状的 `known=100 / mistaken=30 / else=50`(原逻辑把自评和对错压成一维)。

#### ② 跟读背诵 = 单词读音 + 1~N 句子,各半

```
cell = 单词读音分 × 0.5 + 句子平均分 × 0.5
```
- 句子先在内部平均,再与单词各占一半 → 句子条数多不会冲淡单词读音。
- 无句子 → cell = 单词读音分;某句评分失败 → 跳过并在句子内部归一。

#### ③ 关卡小测 = 每词 2 题(听音填空 + 背诵评测),等权平均

> 页面术语(`pages/listen/`):第 1 步「听音填空」、第 2 步「背诵评测」。

```
cell = (听音填空分 + 背诵评测分) / 2   // 每题先归一到 0-100
```
- 第 1 题 **听音填空**(听音后点词块填空)→ 0 / 100(整词填对/错;若多空可按填对空数比例)。
- 第 2 题 **背诵评测**(看中文脱稿背诵 + 语音评测)→ 发音分 0-100。
- 等价现有 `computeQuizScoreRate` 的单词口径(`fillCorrect` + `reciteScore`),从全环节下沉到每词。

### 5.7 跟读 vs 背诵:两种技能,均保留(方案 B,已确认)

口语产出分出现在两处,但**是两种不同技能,不是重复计分**:

| 环节 | 页面称呼 | 形式 | 难度 |
|---|---|---|---|
| 环节② | 跟读背诵 | 有范读提示,看着 / 听着模仿 | 较低 |
| 小测第 2 题 | **背诵评测** | 看中文脱稿产出,无提示 | 较高 |

→ 两者均计入掌握度,体现"模仿 → 脱稿"的进阶,**不做去重**。

**由此得到的技能权重分布(透明列出,便于你确认是否符合预期):**

| 技能类 | 来源 | 占词掌握度 |
|---|---|---|
| 口语产出(跟读 + 背诵评测) | 跟读 30% + 小测背诵(50%的一半) 25% | **≈ 55%** |
| 认读(选择 + 听音填空) | 新学选择(20%内) + 小测听音填空 25% | **≈ 45%** |

> 对"少儿口语"定位,产出略重于认读(55/45)是合理的;若想调,改 5.2 环节权重即可。

## 6. 复习规则

### 6.1 进队列(入口)= 首次种子

- 复习种子 = **首次那次**算出的 `mastery < MASTERY_THRESHOLD` 的词集合,**冻结**。
- 重练原关卡 **不改变** 复习种子(首次锁定)。

### 6.2 出队列(毕业)= 在复习环节内完成

- **毕业在「复习」独立场景里完成,不在重刷原关卡里完成。**
- 孩子在复习环节把某词做达标 → 该词出队列(或进入更长的复习间隔)。
- 这样"首次种子 + 复习内消化"形成闭环,避免"练好了错词还赖着"的死队列。

### 6.3 兜底口子(先不做,埋点)

首次"蒙对"的词永远进不了复习。若后续发现复习覆盖不足:
入口规则从"首次错"扩为 **"首次错 ∪ 任意一次明显退步"**,而非退回"跟最近一次"。

## 7. 接口 / 字段约定

### 7.1 提交练习成绩(每个词带分环节分)

```jsonc
{
  "levelId": "L1",
  "isFirstSubmit": true,            // 是否首次提交(后端也应自行判定)
  "words": [
    {
      "content": "pencil",
      "sections": {                 // 没有的环节给 null,参与归一化时跳过
        "wordNew": 100,             // 单词新学 0-100
        "recite": 70,               // 跟读背诵 0-100
        "quiz": 40                  // 关卡小测 0-100
      }
    }
  ]
}
```

### 7.2 报告返回(由后端按本规则算好)

```jsonc
{
  "levelId": "L1",
  "resBookId": "rb_xxx",
  "scoreRate": 92,
  "maxScoreRate": 92,
  "latestScoreRate": 92,
  "stars": 3,
  "unlockNext": true,
  "minutes": 18,
  "durationSeconds": 1080,
  "reportGeneratedAt": "2026-06-16T14:35:00+08:00",
  "sectionScores": {
    "wordNew": {
      "score": 95,
      "submittedAt": "2026-06-16T14:20:00+08:00",
      "refreshedAt": "2026-06-16T14:30:00+08:00"
    },
    "recite": {
      "score": 89,
      "submittedAt": "2026-06-16T14:25:00+08:00",
      "refreshedAt": "2026-06-15T20:10:00+08:00"
    },
    "quiz": {
      "score": 92,
      "submittedAt": "2026-06-16T14:32:00+08:00",
      "refreshedAt": "2026-06-16T14:32:00+08:00"
    }
  },
  "masteredCount": 11,
  "reviewCount": 1,
  "words": [ … ]
}
```

- **`submittedAt`**：该环节**最近一次成绩提交**时间（finish / save-learning-record 或环节收口时写入）。
- **`refreshedAt`**：该环节**当前展示分（历史最高）**的刷新时间；刷出新高分时更新，可与 `submittedAt` 相同。
- **`reportGeneratedAt`**：本关报告快照生成时间（`GET unit-report` 返回时由后端填充）。
- **`minutes` / `durationSeconds`**：本关总练习用时（三环节之和，后端汇总）。

### 7.2b 入门/结业测报告时间字段

`GET exam-result` 在成绩字段之外须返回：

```jsonc
{
  "durationSeconds": 892,
  "minutes": 15,
  "startedAt": "2026-06-16T10:01:00+08:00",
  "finishedAt": "2026-06-16T10:15:52+08:00",
  "reportGeneratedAt": "2026-06-16T10:15:53+08:00"
}
```

- **`durationSeconds` / `minutes`**：测评练习用时（intro→交卷）。
- **`reportGeneratedAt`**：报告生成时间（交卷计分完成后；通常略晚于 `finishedAt`）。

### 7.3 复习资源(替换 `utils/review-mock.js`)

- 入参:`levelId` / `reviewUnitIds` 或用户维度。
- 出参:与 `getUnitResource` 同结构的词列表(页面无需改),来源 = **首次种子中尚未毕业**的词。
- 毕业写回:复习环节达标后调用毕业接口,把对应词移出队列 / 延长间隔。

## 8. 前端落地点(最小改动)

1. `finish-stars.js`:新增 `computeWordMastery(sections, weights)`(归一化加权)与 `MASTERY_THRESHOLD`;`已掌握/待复习` 与 `总正确率` 改为基于 mastery。
2. 展示分接入 `maxScoreRate`(历史最高),晋级 gate 用 `>= 55`。
3. `review-mock.js`:按 7.3 换真接口,复习集合 = 首次种子未毕业项。
4. `pages/report/`(学习报告页,已先按 mock 实现 UI):
   - 环节卡片显示 `submittedAt` / `refreshedAt`（前端格式化为「M/D HH:mm 提交/刷新」）。
   - 报告头或底部可展示 `reportGeneratedAt`（报告生成时间）。
   - 顶部鼓励语 `encourage`：规则见 `utils/report-copy.js`（≥95 / ≥85 / 有待复习词 / 默认四档）。

5. `pages/exam/exam-report`：等级徽章 `grade`、顶部评语 `encourage`、模块/题型 `statusText` 规则见 `utils/exam-report-copy.js`；后端 `exam-result` 可直返或前端按正确率计算。
